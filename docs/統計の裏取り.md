# 統計での裏取り（油種構成・販売量）

名簿の数字（油種ごとの1日消費・タンク容量）は、これまで**すべて仮置**だった。
「石油消費統計を参照しては」という指摘（2026-09-16）を受けて、公開統計に当たった記録。

---

## 1. 1SSあたりの月間販売量（実測値・出典あり）

**SS過疎地等実態調査**（平成30年度・資源エネルギー庁委託、全国石油協会が実施）

| 油種 | 月間販売量 | サンプル数 |
|---|---|---|
| ガソリン | **42.9 kL** | 373 |
| 灯油（春夏） | **11.9 kL** | 358 |
| 灯油（秋冬） | **36.8 kL** | 363 |
| 軽油 | **32.3 kL** | 370 |

出典: 資源エネルギー庁 資源・燃料部 石油流通課「SS過疎地等の現状について」
（2021年12月1日、資料2、スライド13）
https://www.enecho.meti.go.jp/category/resources_and_fuel/distribution/sskasochi/R3kenkyukai/001/PDF/001_002.pdf

**この調査の対象はSS過疎地等**＝市町村内のSSが3か所以下、または最寄りSSまで15km以上の
エリア。**郊外・山陰側のSSの姿**として読むのが妥当で、広島市内のSSには当てはめにくい。

稼働25日で割ると**1日あたり ガソリン1.72kL／軽油1.29kL／灯油(秋冬)1.47kL／灯油(春夏)0.48kL**。

### ここから分かること

1. **灯油の季節差は約3.1倍**（36.8 ÷ 11.9）。モデルの季節乗数は冬2.6倍・夏0.15倍で、
   冬/夏＝17倍。**冬/春夏平均で見ると統計の3.1倍より大きい**。要見直し。
2. **軽油はガソリンの0.75倍**（32.3 ÷ 42.9）と、思ったより大きい。モデルは郊外SSで
   0.47倍、市内SSで0.30倍しかない。**軽油を小さく置きすぎている**。
3. モデルの1軒あたりの量は、郊外SSで統計の半分ほど（ガソリン0.86 対 1.72）。

## 2. ハイオクの比率（生産量の統計で確定）

**経済産業省 生産動態統計（資源・エネルギー統計 確報・製品月表「石油製品」）**は、
ガソリンを**「自動車用ガソリン 高級（ハイオク）」と「並級（レギュラー）」に分けて**
集計している。元売の生産実績そのもの。

| 区分 | 生産 | 出荷（販売部門） |
|---|---|---|
| 自動車用ガソリン 高級 | 710,126 | 738,301 |
| 自動車用ガソリン 並級 | 4,188,246 | 4,291,392 |
| **ハイオクの比率** | **14.5%** | **14.7%** |

出典: e-Stat 統計表 https://www.e-stat.go.jp/dbview?sid=0003058575 （公開 2011-03-31）

**モデルの13〜15%は、この統計とほぼ一致していた。** 実務の指摘「8:2以下、ふつう15%を
超えない」とも合う。**粗利の構成比から8%前後と推定したのは誤り**（ハイオクは1Lあたりの
粗利が大きいので、粗利比から数量比は割り出せない）。

**注意**: この表は公開が2011年で古い。ハイオク需要はその後減っているとされるので、
直近では14.5%より下がっている可能性がある。直近年の同じ系列は未入手。

## 2.1 季節の効き方（全国の販売量・2023年）

石油統計年報の月別販売量（全国）から、季節係数を計算した。

| 季節 | 灯油 | ガソリン | 軽油 |
|---|---|---|---|
| 冬（12〜2月） | **2.58** | 0.98 | 0.93 |
| 春（3〜5月） | **1.05** | 0.99 | 0.96 |
| 夏（6〜8月） | **0.46** | 1.07 | 0.97 |
| 秋（9〜11月） | 1.00 | 1.00 | 1.00 |

（秋を1.00に揃えた値。モデルの `SEASON_MULTIPLIER` と同じ置き方）

出典: e-Stat 石油統計 年報 https://www.e-stat.go.jp/dbview?sid=0003171992

**モデルの季節乗数との比較**

| 油種 | モデル（冬/春/夏） | 統計（冬/春/夏） |
|---|---|---|
| 灯油 | 2.6 / 0.8 / **0.15** | 2.58 / 1.05 / **0.46** |
| ガソリン | 0.95 / 1.0 / 1.1 | 0.98 / 0.99 / 1.07 |
| 軽油 | 1.0 / 1.0 / 1.05 | 0.93 / 0.96 / 0.97 |

**冬の灯油2.6倍は当たっていた。** 外れているのは**夏の灯油（0.15 → 0.46）**と
春（0.8 → 1.05）。夏を低く置きすぎている。

年計では**軽油/ガソリン＝0.74、灯油/ガソリン＝0.31**（全国）。§1のSS統計（0.75）と一致する。

## 2.2 （古い推定・撤回）粗利からのハイオク比率

**粗利額の構造**（2020年度調査・全国石油協会「石油製品販売業経営実態調査」）

| 油種 | 粗利額 | 構成比 |
|---|---|---|
| レギュラー | 32百万円 | 36.4% |
| **ハイオク** | **3百万円** | **3.8%** |
| 軽油 | 18百万円 | 20.5% |
| 灯油 | 10百万円 | 11.0% |
| A重油 | 3百万円 | 3.8% |

出典: 同上スライド4（原典は全国石油協会の経営実態調査）

**販売量の比率ではなく粗利の比率**。ハイオクは1Lあたりの粗利が大きいので、
**数量の比率はこれより小さい**。粗利ベースでガソリンに占めるハイオクは
3.8 ÷ (36.4 + 3.8) ＝ **9.5%**。数量ベースはこれ以下＝**おおむね8%前後**と読める。

実務の指摘（2026-09-16）「レギュラー:ハイオクは8:2以下、ふつう15%を超えない」とも整合。
**モデルの13〜15%は上限に張り付いていた。**

## 3. 直す候補（未実施・要相談）

| 項目 | いま | 統計から | 判断 |
|---|---|---|---|
| ハイオク比率 | 13〜15% | **14.5%**（生産量統計） | **直す必要なし** |
| 灯油 冬 | 2.6 | **2.58** | **直す必要なし** |
| 灯油 夏 | 0.15 | **0.46** | 直す（夏が低すぎ） |
| 灯油 春 | 0.8 | **1.05** | 直す |
| 軽油／ガソリン | 郊外0.47・市内0.30 | **0.74〜0.75** | 要判断（量が増える） |
| 1軒の規模（郊外） | ガソリン0.86kL/日 | **1.72kL/日** | 要判断（量が2倍） |

**規模を統計に合わせると需要が約2倍になり、1エリア15軒あたりの台数が変わる**
（いまは冬で2〜3台）。体制設計（専属14〜20台）の答えも動く。合わせるかどうかは要判断。

**市内SSの統計は未入手。** この調査は過疎地が対象なので、広島市内の姿は別途要る
（全国石油協会の経営実態調査の本体は有償・非公開部分がある）。
