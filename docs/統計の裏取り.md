# 統計での裏取り（油種構成・販売量）

「石油消費統計を参照しては」という指摘（2026-09-16）を受けて、公開統計に当たった記録。

## 1. 1SSあたりの月間販売量（実測値・出典あり）

**SS過疎地等実態調査**（平成30年度・資源エネルギー庁委託、全国石油協会が実施）

| 油種 | 月間販売量 | サンプル数 |
|---|---|---|
| ガソリン | **42.9 kL** | 373 |
| 灯油（春夏） | **11.9 kL** | 358 |
| 灯油（秋冬） | **36.8 kL** | 363 |
| 軽油 | **32.3 kL** | 370 |

出典: 資源エネルギー庁 資源・燃料部 石油流通課「SS過疎地等の現状について」
（2021年12月1日、資料2、スライド13）
https://www.enecho.meti.go.jp/category/resources_and_fuel/distribution/sskasochi/R3kenkyukai/001/PDF/001_002.pdf

**この調査の対象はSS過疎地等**＝市町村内のSSが3か所以下、または最寄りSSまで15km以上の
エリア。**郊外・山陰側のSSの姿**として読むのが妥当で、広島市内のSSには当てはめにくい。

稼働25日で割ると**1日あたり ガソリン1.72kL／軽油1.29kL／灯油(秋冬)1.47kL／灯油(春夏)0.48kL**。

### ここから分かること

1. **灯油の季節差は約3.1倍**（36.8 ÷ 11.9）。モデルの季節乗数は冬2.6倍・夏0.15倍で、
   冬/夏＝17倍。**冬/春夏平均で見ると統計の3.1倍より大きい**。要見直し。
2. **軽油はガソリンの0.75倍**（32.3 ÷ 42.9）と、思ったより大きい。モデルは郊外SSで
   0.47倍、市内SSで0.30倍しかない。**軽油を小さく置きすぎている**。
3. モデルの1軒あたりの量は、郊外SSで統計の半分ほど（ガソリン0.86 対 1.72）。

## 2. ハイオクの比率

**粗利額の構造**（2020年度調査・全国石油協会「石油製品販売業経営実態調査」）

| 油種 | 粗利額 | 構成比 |
|---|---|---|
| レギュラー | 32百万円 | 36.4% |
| **ハイオク** | **3百万円** | **3.8%** |
| 軽油 | 18百万円 | 20.5% |
| 灯油 | 10百万円 | 11.0% |
| A重油 | 3百万円 | 3.8% |

出典: 同上スライド4（原典は全国石油協会の経営実態調査）

**販売量の比率ではなく粗利の比率**。ハイオクは1Lあたりの粗利が大きいので、
**数量の比率はこれより小さい**。粗利ベースでガソリンに占めるハイオクは
3.8 ÷ (36.4 + 3.8) ＝ **9.5%**。数量ベースはこれ以下＝**おおむね8%前後**と読める。

実務の指摘（2026-09-16）「レギュラー:ハイオクは8:2以下、ふつう15%を超えない」とも整合。
**モデルの13〜15%は上限に張り付いていた。**

## 3. 直す候補（未実施・要相談）

| 項目 | いま | 統計から |
|---|---|---|
| ハイオク比率 | 13〜15% | **8%前後** |
| 軽油／ガソリン | 郊外0.47・市内0.30 | **0.75**（郊外・幹線沿い） |
| 灯油の季節差 | 冬2.6／夏0.15 | **秋冬/春夏＝3.1倍** |
| 1軒の規模（郊外） | ガソリン0.86kL/日 | **1.72kL/日** |

**規模を統計に合わせると需要が約2倍になり、1エリア15軒あたりの台数が変わる**
（いまは冬で2〜3台）。体制設計（専属14〜20台）の答えも動く。合わせるかどうかは要判断。

**市内SSの統計は未入手。** この調査は過疎地が対象なので、広島市内の姿は別途要る
（全国石油協会の経営実態調査の本体は有償・非公開部分がある）。
