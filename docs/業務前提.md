# 業務前提

このシステムが何を「現実」として扱っているかの一覧。

**なぜ文書にするか。** これらはコードを読んでも分からない。「拘束13時間」も
「高速は50km」も、コードの中では定数1個にしか見えないが、間違っていれば
計画そのものが嘘になる。定数の**出どころ**と**確からしさ**を、定数とは
別の場所に持っておく必要がある。

**出どころの区分**を各項目に付けてある。

| 印 | 意味 |
|---|---|
| 法令 | 条文・告示で確認済み。出典を併記 |
| 実務 | 津江（元・石油会社／製油所IS 25年）の指摘 |
| 仮置 | **裏が取れていない。** モデルが動くために置いただけの数字 |

仮置のまま提出する項目があってよい。まずいのは、仮置を実務だと思って
読むことのほう。

## 1. 乗務員の時間

### 1.1 拘束時間・運転時間（改善基準告示・2024年4月適用）

| 項目 | 値 | 区分 |
|---|---|---|
| 1日の拘束時間 | 原則13時間（最大15時間） | 法令 |
| 1日の運転時間 | 2日平均で9時間 | 法令 |
| 連続運転 | 4時間まで | 法令 |
| 連続運転の中断 | 1回10分以上、合計30分以上（430休憩） | 法令 |
| 休息期間 | 継続11時間を基本、9時間を下回らない | 法令・**未実装** |

出典: [国交省 トラック運転者の改善基準告示（2024年4月適用）](https://wwwtb.mlit.go.jp/kinki/content/000306033.pdf)

**一人あたりの拘束は13時間**であって12時間ではない。二交代でも引継ぎが
あるので13時間で見る。（実務）

### 1.2 休憩（労働基準法34条）

| 労働時間 | 必要な休憩 | 区分 |
|---|---|---|
| 6時間以下 | 不要 | 法令 |
| 6時間超〜8時間 | 45分以上 | 法令 |
| 8時間超 | 1時間以上 | 法令 |
| 12時間超 | **追加規定なし** | 法令 |

出典: [厚生労働省 休憩時間は法律で決まっていますか](https://www.mhlw.go.jp/bunya/roudoukijun/faq_kijyunhou_13.html)

**上に段は無い。** 12時間で1時間30分、16時間で2時間といった比例付与は
義務づけられていない。上乗せがあるとすれば就業規則か労働協約の側の話。

**基準は労働時間であって拘束時間ではない。** 拘束＝労働＋休憩なので、
どの段に当たるかは休憩を引いた後で決まる。逆算した拘束時間の閾値:

    拘束 ≤ 360分（6時間）      → 0分
    拘束 ≤ 525分（480 + 45）   → 45分
    拘束 > 525分               → 60分

### 1.3 430休憩と労基法の休憩は足さない

2024年4月の改正で、430の「運転の中断」は**原則として休憩**とされ、
荷積み・荷卸しを算入できなくなった。つまり430の30分は労基法34条の休憩の
**内数**であって別枠ではない。要る休憩は**両者の大きいほう**。

出典: [430休憩とは（ハコベル）](https://www.hacobell.com/media/430-rest)

拘束13時間の計画に休憩30分しか積んでいなかったのが当初の実装で、
**労基法上30分足りない計画**を出していた。

### 1.4 休憩は場所を選ぶ（実務）

**ローリーはどこででも休憩できない。** 停められるのは実質この3つ。

- 麻里布油槽所の待機場（便と便の間。積込で戻るので回送が要らない）
- 高速道路のSA/PA（その便が高速に乗っている場合だけ）
- 運送会社の車庫（戻る回送が要る）

コンビニや路上に停めるとクレームになる。**ローリーは元売りの看板を背負って
走っている**ので、不適切な場所に停まっていること自体が元売りへの苦情になり、
運送会社の信用に返ってくる。需要家の構内も駄目で、荷役中は労働時間なので
休憩に算入できない（1.3）。

危ないのは「**高速に乗らない便で、連続運転が4時間を超える**」形。
`solver.diagnostics["break_location_risk"]` で検出している。**計画は変えて
いない**（回送の時間をどう見積もるかが決まっていないため）。

15軒の名簿では発火しないが、名簿が増えて1便5〜6軒の郊外ループが出ると
境目に来る。

## 2. 時間の内訳

| 項目 | いまの値 | 区分 |
|---|---|---|
| 積込（麻里布） | 40分／便・全車共通 | **仮置** |
| 荷卸・郊外GS | 30分 | **仮置** |
| 荷卸・市内GS | 35分 | **仮置** |
| 荷卸・山陰GS | 40分 | **仮置** |
| 荷卸・運送会社営業所 | 45分 | **仮置** |

**構造そのものが疑わしい。** いまは需要家ごとの定数で、**降ろす量と無関係**。
1軒に2kL置くのも8kL置くのも同じ35分になっている。荷卸しはローリーからの
**自然落下**なので流下そのものが時間を食うはずで、本来は

    荷卸時間 ＝ 固定（着車・アース・ホース接続・検尺・伝票）＋ 量 × 流下の単位時間

の形。積込も同様で、**油種の数**（槽ごとに別の油種＝アームの切替）が
効くはずだが、これも40分の定数。

**未確認**（実務の数字待ち）:

- 自然落下で4kL槽1本を降ろすのに何分か
- 1軒の固定分（着車から流下開始まで＋検尺・伝票）は何分か
- 積込40分は妥当か。油種4つと1つで差はあるか

量比例を入れると1便に回れる軒数が減るので、**拘束13時間の張り付きは
さらに厳しくなる**方向。

## 3. 車両

| 車格 | 実在する容量 | 区分 |
|---|---|---|
| 単車 | 14kL / 16kL | 実務 |
| トレーラー | 18kL / 20kL / 24kL / 26kL | 実務 |

上記以外の容量の車は作らない（`Vehicle.__post_init__` が弾く）。
最初の実装には10kL車が居たが、**そんなローリーは無い**。

**単車は小さいSSや構内の狭い先へ優先配車**される。トレーラーが物理的に
入れないため。積載量の問題ではないので、容量制約とは別に持つ
（`Customer.accepts_trailer`）。荷役条件は実務ではマスター化されている。

**24時間稼働が可能。** 乗務員を交代して乗り換える二交代制。ただし夜間に
降ろせる先が確保できている見合いだけ。（実務）

## 4. 高速道路

**使用基準は距離。** 麻里布からの入口は**大竹IC・岩国ICの2か所**で、
主に大竹。境目は**50km前後**。（実務）

料金は**元売が負担**する。ただし基準があり、**運送会社の判断で使う場合は
自腹**。したがって基準内なら時間だけで判断してよい。（実務）

モデルでは**道路距離50km超**で高速を使う（`travel.EXPRESSWAY_THRESHOLD_KM`）。

**迂回率と速度は切り離す。** 高速に乗ろうが中国山地は迂回する。
地形は道路の種類では変わらない。

| | 値 | 決まるもの |
|---|---|---|
| 迂回率 | 山越え1.90 / 市街地1.75 / それ以外1.70 | 地形 |
| 速度 | 高速62 / 幹線42 / 山道40 / 市街地24 km/h | 高速利用の有無 |

実距離・実所要時間との突き合わせは8ルートで実施済み（残差はすべて
モデルが遅い側＝安全側）。詳細はコミット 6587fe0。

## 5. 需要と体制

**因果の向きを間違えない。**

    地区全体の需要
      × ENEOSのシェア（％）
      × その運送会社への引き当て割合
      ＝ その運送会社が担う需要
      → 必要なローリー台数
      → 必要な乗務員数（二交代を入れるか否かを含む）
      → 半期（4-9月／10-3月）ごとの専属契約台数 ＋ 非専属の確保

**回転数も走行距離も制約ではなく結果。**（実務）

| 指標 | 実務の目安 | 区分 |
|---|---|---|
| 回転数 | 日中稼働（1人）で3回転程度、二交代の24時間対応で6回転 | 実務 |
| 走行距離 | 500〜600km／台 | 実務 |
| 拘束時間 | 13時間前後 | 実務 |

近場ばかりで5回転になる場合もあるが、荷役の負担が重くその乗務員は割を食う。

### 5.1 専属と非専属

- **専属**: 元売が半期ごとに台数を提示。**最低保証稼働**があり単価が少し安い
- **非専属**: 最低保証なし（動かした分だけ）、単価は高い。故障や需要上振れに備えて運送会社が自前で確保
- **最低保証の単位**: 容量 × 走行距離 ÷（台数 × 日数）＝ **kL・km**（石油版のトンキロ）
- 運賃 ＝ max(実績, 保証) × 単価 という閾値構造
- **予測誤差のリスクは運送会社が負う。** 需要予測は元売、外れたら運送会社が非専属で自腹で埋める

半期ごとに契約し直すので、**次期の専属台数の試算を出せること自体が価値**になる。

### 5.2 季節

冬に灯油需要が増えれば必要台数が増える。運送会社は**冬場の季節労働者
（出稼ぎ）**を活用して乗務員を確保する。（実務）

## 6. 優先順位

**欠品が最上位。労基超過は回数を数えるコスト。**（実務）

- 欠品は元売りの信用問題
- 労基は運送会社が指導勧告か罰金
- 会社規模と取引の関係から、**運送会社が泣くのが常**

**ただし恒常化はコンプライアンス上の大問題。** 一時的なら労基上の例外扱いが
あり、欠品にも補償で逃げる手段がある。どちらも「一時的なら可、恒常的なら
構造の欠陥」という同じ形をしている。

逃げ道は3つあり、すべて同じ機構で扱う。

1. 拘束時間の延長
2. 配送圏の越境
3. 欠品

**累積を監視して、恒常化したら構造の見直し提案に切り替える。**
これが本PJの新規性の核。

## 7. 配送圏の境界

**境港油槽所**へ、麻里布製油所または水島製油所から転送輸送が発生する
（麻里布が優先）。これにより境港油槽所と麻里布の配送圏の境が**コストで
動く**。水島・徳山との境でも同じことが起きる。（実務）

**在庫が切れる話になれば、コストの制約は変わる**（越境が正当化される）。

境港を「需要家」として名簿に置けば、当日モデルはほぼ無改造で扱える。

## 8. 無人荷卸し

元売りは24時間営業や夜間の無人荷卸しができるシステムを展開している。
投資よりコスト削減につながるため。**通勤ラッシュに巻き込まれる配送エリアの
受入先で効果が大きい**（＝広島市内が該当）。（実務）

**受入枠は営業時間ではなく無人荷卸し設備で決まる。**

**未確認**: 無人荷卸しの消防法要件。
